# Players Directory

This directory contains detailed analysis files for individual banking players.

## Naming Convention

Files should follow this format:
- `[country-code]-[player-name].md`

Examples:
- `us-chime.md`
- `us-chase.md`
- `br-nubank.md`
- `uk-revolut.md`
- `de-n26.md`

## File Structure

Each player file should follow the template defined in `/ANALYSIS_METHODOLOGY.md`

Key sections:
1. Overview (company details)
2. Business model
3. Product catalog (organized by category)
4. Competitive advantages
5. Recent innovations
6. Partnerships
7. References
