# Categories Directory

This directory contains feature mappings organized by product/service category.

## Category Files

Each category file maps features to players offering them, creating a cross-reference view.

### Planned Categories

Based on the taxonomy in `/ANALYSIS_METHODOLOGY.md`:

1. `account-types.md` - Checking, savings, money market, CDs
2. `cards.md` - Debit, credit, virtual cards, card controls
3. `payments-transfers.md` - P2P, international, bill pay
4. `credit-lending.md` - Loans, credit lines, overdraft
5. `investments.md` - Brokerage, robo-advisors, crypto
6. `rewards-loyalty.md` - Cashback, points, referrals
7. `money-management.md` - Budgeting, credit scores, goals
8. `security-fraud.md` - 2FA, monitoring, protection
9. `insurance.md` - Life, health, travel, device
10. `travel.md` - Booking, lounge access, no FX fees
11. `marketplace.md` - Shopping, deals, merchant services
12. `education-support.md` - Content, support channels
13. `family-features.md` - Teen accounts, parental controls
14. `business-features.md` - Business banking, payroll
15. `integrations.md` - APIs, third-party connections
16. `accessibility-ux.md` - Platforms, languages, voice
17. `additional-services.md` - ATM access, checks, HSA

## File Format

Each category file should include:
- Category overview and importance
- Feature inventory (what variations exist)
- Player-by-player breakdown
- Innovation trends
- Best practices
- Geographic differences

## Cross-Reference

Category files link back to player files in `/players/` directory, creating a bidirectional map:
- Player file → Lists all features they offer
- Category file → Lists all players offering specific features
